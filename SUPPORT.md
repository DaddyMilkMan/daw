### 🐛 Bug Reports

If you encounter a bug, please report it using our [GitHub issue tracker](https://github.com/your-repo/zenith-daw/issues):

1. Search existing issues to avoid duplicates
2. Create a new issue with:
   - Clear title describing the bug
   - Detailed description of the issue
   - Steps to reproduce the problem
   - Expected vs actual behavior
   - System information (OS, version, etc.)
   - Screenshots or error messages if applicable

## Reporting Issues

### 🐛 Bug Report Template

When reporting bugs, please use this template:

```markdown
## Bug Description
[Clear description of the issue]

## Steps to Reproduce
1. [First step]
2. [Second step]
3. [Expected result]
4. [Actual result]

## Environment
- Operating System: [e.g., Windows 11]
- Zenith DAW Version: [e.g., 2.0.0]
- Hardware: [e.g., MacBook Pro 2021]
- Audio Interface: [e.g., Focusrite Scarlett 2i2]

## Expected Behavior
[What should happen]

## Actual Behavior
[What actually happens]

## Additional Context
[Any other relevant information, screenshots, error logs]
```
