# Vexel DAW

AI-Native Digital Audio Workstation with Wingman Integration

## 🚀 Quick Start (Super Simple!)

```bash
cd vexel-daw
npm install
npm run dev
```

That's it! The DAW will open automatically.

## What You'll See

- **Transport Bar** - Play, pause, stop controls with tempo adjustment
- **Left Panel** - Browser for sounds, plugins, samples
- **Center** - Arrangement view with timeline
- **Right Panel** - Mixer with volume/pan controls
- **Wingman AI** - Click the "Wingman AI" button to chat with AI

## Try These:

1. Click "Add Track" to create a track
2. Click "Wingman AI" button (top right)
3. Try asking: "Create a trap beat"
4. Adjust tempo in the transport bar
5. Play/pause with spacebar

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for production
npm run build:app
```
