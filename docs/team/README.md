## 🎨 The Neon Noir Aesthetic

### Color Palette
- **Primary**: Cyan (#00FFFF) - accents and highlights
- **Secondary**: Magenta (#FF00FF) - secondary accents
- **Active**: Neon Green (#00FF64) - active states
- **Warning**: Amber (#FFC800)
- **Danger**: Red (#FF3232)
- **Background**: Dark blue-grey gradients
- **Glass**: Semi-transparent white (10-40%)

### Visual Style
- ✨ **Glassmorphism** - Semi-transparent panels with blur
- 💫 **Glow Effects** - Neon accents on hover/active
- 🌈 **Gradients** - Smooth color transitions
- 🎭 **Micro-animations** - Everything feels alive
- 📐 **Perfect Spacing** - 8px grid system

   - SkiaButton (4 styles)
   - SkiaKnob (rotary control)

- Performance optimization (60FPS guaranteed)
