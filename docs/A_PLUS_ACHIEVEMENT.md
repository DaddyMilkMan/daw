## 📚 HOW TO USE NEW FEATURES

### 1. Plugin State Persistence
```cpp
// Saving
Track track(projectState, "track-001");
juce::ValueTree pluginTree("Plugin");
track.savePluginState(pluginInstance, pluginTree);

// Loading
track.loadPluginState(pluginTree, pluginHost);
```

### 2. Async Plugin Scanning
```cpp
pluginHost.scanAsync([](int current, int total, const juce::String& name) {
    std::cout << "Scanning: " << name << " (" 
              << current << "/" << total << ")\n";
});

// Cancel if needed
pluginHost.cancelScan();
```

### 3. Stem Separation
```cpp
ONNXStemSeparator separator;
separator.loadModel(modelFile);
separator.process(audioBuffer, ONNXStemSeparator::StemType::Vocals);
```
