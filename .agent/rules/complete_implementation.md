# Complete Implementation & Integration
1. **No Stubs**: Never leave " TODO\ or placeholder stubs in code you commit. If you start a task, finish it.
2. **End-to-End Implementation**: A task is not done until the component is instantiated, connected to the engine, and visible on screen.
3. **Verify Integration**: Changing a class definition is not enough. You must update the calling code and verify the build.
4. **Immediate Clean-Up**: If you create a temporary resource, delete it in the same session.
