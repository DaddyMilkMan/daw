## 🎯 Usage Examples

### Component Colors

```cpp
// BACKGROUNDS
auto windowBG     = juce::Colour(Elevation::dp0);   // Main window
auto panelBG      = juce::Colour(Elevation::dp2);   // Browser, mixer
auto cardBG       = juce::Colour(Elevation::dp1);   // Track headers
auto buttonBG     = juce::Colour(Elevation::dp4);   // Default button
auto hoverBG      = juce::Colour(Elevation::dp8);   // Hover state
auto modalBG      = juce::Colour(Elevation::dp24);  // Dialogs

// ACCENTS
auto primaryBtn   = juce::Colour(Colors::accentPrimary);        // #00d9ff
auto primaryHover = juce::Colour(Colors::accentPrimaryHover);   // #33e0ff
auto secondaryBtn = juce::Colour(Colors::accentSecondary);      // #ff8c42

// TEXT
auto mainText     = juce::Colour(Colors::textPrimary);    // #dedede (87% white)
auto labelText    = juce::Colour(Colors::textSecondary);  // #999999 (60% white)
auto disabledText = juce::Colour(Colors::textDisabled);   // #616161 (38% white)
auto onAccentText = juce::Colour(Colors::textOnAccent);   // #000000 (black)

// SEMANTIC
auto successColor = juce::Colour(Colors::success);  // #4caf50
auto warningColor = juce::Colour(Colors::warning);  // #ffc107
auto dangerColor  = juce::Colour(Colors::danger);   // #ff5252
auto infoColor    = juce::Colour(Colors::info);     // #2196f3
```

### Track Color Assignment

```cpp
// Get track color by index (cycles through 12 colors)
for (int i = 0; i < numTracks; ++i)
{
    auto trackColor = ZenithLookAndFeel::getTrackColor(i);
    
    // Use at 15% opacity for track background
    g.setColour(trackColor.withAlpha(0.15f));
    g.fillRect(trackBounds);
    
    // Full opacity for left edge indicator
    g.setColour(trackColor);
    g.fillRect(trackBounds.removeFromLeft(3));
}
```

## 🎨 Color Combinations

### High Contrast Combinations (WCAG AAA)

| Foreground | Background | Contrast | Use Case |
|------------|------------|----------|----------|
| `#dedede` | `#121212` | **15.8:1** | Main text on base |
| `#dedede` | `#232323` | **13.1:1** | Text on panels |
| `#000000` | `#00d9ff` | **10.9:1** | Text on primary accent |
| `#999999` | `#121212` | **7.5:1** | Secondary text |
| `#dedede` | `#2e2e2e` | **10.2:1** | Text on hover |

### Safe Color Pairs (for color blindness)

| Pair | Reason |
|------|--------|
| Blue + Orange | Most universally distinguishable |
| Cyan + Red | High contrast, deuteranomaly-safe |
| Blue + Brown | Safe for all types |

**Avoid**: Red + Green (8% of men can't distinguish)

## 📐 Quick Reference

### When to Use Each Color

**Primary Accent (Cyan `#00d9ff`)**
- Active buttons
- Selected items
- Progress indicators
- Focus outlines
- Important CTAs

**Secondary Accent (Orange `#ff8c42`)**
- Secondary actions
- Alternative buttons
- Warning states (combined with amber)
- Highlights

**Success Green `#4caf50`**
- Play button
- Success messages
- Level meters (safe zone)
- Confirmations

**Warning Amber `#ffc107`**
- Warnings
- Level meters (caution)
- Alerts
- Important notices

**Danger Red `#ff5252`**
- Record button
- Delete actions
- Level meters (clipping)
- Error messages
- Destructive actions

**Info Blue `#2196f3`**
- Informational messages
- Tips
- Help indicators
- Cool-toned highlights

## 🔍 Accessibility Check

### Contrast Ratio Standards

```
WCAG AA (Minimum)
├─ Normal text: 4.5:1
└─ Large text: 3.0:1

WCAG AAA (Enhanced) ← Our Target
├─ Normal text: 7.0:1
└─ Large text: 4.5:1

UI Components: 3.0:1 minimum
```

### Verify in Code
```cpp
auto ratio = ZenithLookAndFeel::calculateContrastRatio(textColor, bgColor);

if (ratio >= 7.0f) {
    // WCAG AAA compliant ✅
} else if (ratio >= 4.5f) {
    // WCAG AA compliant ⚠️
} else {
    // Non-compliant ❌
}
```

## 🎯 Pro Tips

1. **Use elevation, not custom grays**
   - ✅ `Elevation::dp4`
   - ❌ `0xff2a2a2a`

2. **Text opacity standards**
   - Primary: 87% (`#dedede`)
   - Secondary: 60% (`#999999`)
   - Disabled: 38% (`#616161`)

3. **Track colors cycle automatically**
   ```cpp
   // This handles wrapping automatically
   auto color = getTrackColor(trackIndex);
   ```

4. **Hover states are 10-15% brighter**
   ```cpp
   auto hoverColor = baseColor.brighter(0.15f);
   ```

5. **Pressed states are 20% darker**
   ```cpp
   auto pressedColor = baseColor.darker(0.2f);
   ```

## 📊 Color Distribution

Following the **60-30-10 rule**:

```
60% Neutrals (Elevation system)
├─ Main backgrounds
├─ Panel backgrounds
└─ Component backgrounds

30% Secondary (Orange accent)
├─ Secondary buttons
├─ Alternative actions
└─ Supporting elements

10% Primary (Cyan accent)
├─ CTAs
├─ Active states
└─ Focus indicators
```
