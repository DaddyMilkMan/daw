# DAW

A digital audio workstation project.

## Status

Active development.

## Quick Start

### Build

```bash
make
```

### Run

```bash
./build/daw
```

## Directory Structure

```
.
├── src/          - Source code
├── include/      - Header files
├── build/        - Build output (generated)
└── Makefile      - Build configuration
```
