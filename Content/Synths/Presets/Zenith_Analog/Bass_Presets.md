# Quality Control Checklist

Every preset must pass:

## ✅ Technical
- [ ] No clipping (peak < -0.5 dB)
- [ ] No DC offset
- [ ] No aliasing artifacts
- [ ] Smooth parameter transitions (no clicks)
- [ ] Velocity layers work correctly
- [ ] Modwheel assignments are useful
- [ ] CPU < 3% per voice

## ✅ Musical
- [ ] Gain-staged for mix (average -18 dBFS)
- [ ] EQ-balanced (sits in frequency spectrum)
- [ ] Fits category description
- [ ] Has musical range (can play melodies)
- [ ] Velocity-responsive (expressive)
- [ ] Works in context (tested with drums/bass)

## ✅ Metadata
- [ ] Descriptive name (not "Bass 001")
- [ ] Category assigned
- [ ] Genre tags accurate
- [ ] Mood tags accurate
- [ ] BPM range appropriate
- [ ] Description written by sound designer
- [ ] Quality score 8.0+

## ✅ Sound Design
- [ ] Not generic (has character)
- [ ] Not just "cool demo sound"
- [ ] Actually useful in production
- [ ] Has modulation depth (evolving)
- [ ] Effects enhance (not mask) the sound
- [ ] Tested in real production context

# Testing Protocol

Each preset is tested in:

1. **Solo**: Standalone sound check
2. **With drums**: Does it groove?
3. **With full mix**: Does it sit well?
4. **Different registers**: Low C, middle C, high C
5. **Different velocities**: pp, mp, mf, ff
6. **Different contexts**: 3+ genres

Only presets that pass all 6 tests are included.
