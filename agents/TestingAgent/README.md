# TestingAgent

## Purpose

The **TestingAgent** coordinates comprehensive testing strategies for the DAW, including unit tests, integration tests, and audio-specific validation. It ensures code quality and correctness.

## Triggers

- Test failures detected
- New code changes
- Request for test coverage analysis
- Request for test generation
- Audio validation needed
- Regression testing required

## Outputs

- Test coverage reports
- Test failure analysis
- Generated test cases
- Audio validation results
- Code changes to improve testability
- Testing strategy recommendations

## Acceptance Criteria

- [ ] Analyzes test coverage
- [ ] Generates missing tests
- [ ] Runs audio-specific validation
- [ ] Detects flaky tests
- [ ] Provides test improvement suggestions
- [ ] Integrates with existing test framework
- [ ] Validates RT-safety in tests
- [ ] Generates test reports
