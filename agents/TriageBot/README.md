# TriageBot

## Purpose

The **TriageBot** automatically triages issues, pull requests, and bug reports for the DAW project. It analyzes, categorizes, prioritizes, and routes items to appropriate maintainers.

## Triggers

- New issue opened
- New pull request created
- Issue or PR updated
- Request for issue analysis
- Manual triage requested
- Stale issue detection

## Outputs

- Issue categorization and labels
- Priority assignments
- Maintainer assignments
- Duplicate issue detection
- Related issue linking
- Triage recommendations
- Status updates

## Acceptance Criteria

- [ ] Automatically categorizes issues
- [ ] Assigns appropriate labels
- [ ] Suggests priority levels
- [ ] Detects duplicate issues
- [ ] Routes to appropriate maintainers
- [ ] Links related issues
- [ ] Detects stale issues
- [ ] Provides triage summaries
