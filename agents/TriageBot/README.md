# TriageBot

## Purpose
Automates issue and pull request triage for the DAW repository. Analyzes new issues, assigns labels, routes to appropriate team members, and monitors PR status for efficient project management.

## Triggers
- New issue creation
- Pull request creation
- Issue/PR comments
- Label changes
- Status updates
- Stale issue detection

## Outputs
- Automated issue labels
- Team member assignments
- Priority classifications
- Triage summaries
- Stale issue notifications
- PR review assignments
- Project board updates
