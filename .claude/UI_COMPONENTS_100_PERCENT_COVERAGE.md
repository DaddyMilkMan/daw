## 🎬 Animation Framework

All components use **JUCE 8 Animation Module** for smooth, hardware-synced animations:

### **Animation Types Used**

1. **Fade Animations**
   - Menu open/close opacity transitions
   - Status indicator fades
   - Timeline element appearances

2. **Scale Animations**
   - Button press effects (0.92x scale down)
   - Hover scaling (1.08x scale up)
   - Card animations on interaction

3. **Pulse Animations**
   - Recording indicator pulse effect
   - Beat indicator pulse on each beat
   - Active state pulsing

4. **Linear Transitions**
   - Smooth position changes
   - Fader movement feedback
   - Slider value changes

5. **Spring Effects**
   - Button return-to-normal animation
   - Natural feeling motion
   - Snappy but not jarring

6. **Easing Curves**
   - CSS-standard easings (easeInOut, easeIn, easeOut)
   - Smooth acceleration/deceleration
   - Professional feel

### **Refresh Rate**: 60 Hz (16ms) for smooth visual feedback
